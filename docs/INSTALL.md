FrameDeck インストール手順
==========================

動画制作者向けのファイルブラウザ / プレビューアプリです。
macOS 14 Sonoma 以降で動きます（Apple Silicon / Intel 両対応）。


1. インストール
---------------

dmg を開いて、FrameDeck を Applications フォルダにドラッグしてください。
それだけで完了です。追加で入れるものはありません。


2. 初回起動（ここだけ手間がかかります）
---------------------------------------

「"FrameDeck"は開けません。Appleが悪質なソフトウェアかどうかを
確認できないため...」というメッセージが出ます。

これは Apple の開発者登録（年額 99 ドル）をしていないためで、
アプリに問題があるわけではありません。以下の手順で開けます。

  1. いったん「完了」または「OK」を押してメッセージを閉じる
  2. アップルメニュー →「システム設定」
  3. 左側の「プライバシーとセキュリティ」を選ぶ
  4. 下の方にスクロールすると
     「"FrameDeck"は開発元を確認できないため、使用がブロックされました」
     と出ているので、その横の「このまま開く」を押す
  5. 確認のダイアログで「このまま開く」を押し、Mac のパスワードを入力

2 回目以降は普通にダブルクリックで起動します。

※ macOS 15 以降、以前あった「右クリック → 開く」での回避はできなくなりました。
   上記のシステム設定からの操作が必要です。


ターミナルが使える場合（こちらの方が早いです）

    xattr -dr com.apple.quarantine /Applications/FrameDeck.app

を実行すると、上のダイアログ自体が出なくなります。


3. フォルダへのアクセス許可
---------------------------

デスクトップ・書類・ダウンロードのファイルを最初に開こうとしたとき、
「"FrameDeck"が...フォルダ内のファイルにアクセスしようとしています」
と聞かれます。「許可」を押してください。

このアプリはファイルの読み取りしかしません。
名前の変更・移動・削除はできない作りになっています。
書き込むのは、フレーム書き出しで作る画像だけです。


4. 使い方のさわり
-----------------

  ・ファイルを選んで Space  → プレビューが開く
  ・十字キー                → ファイルの移動（→ でフォルダに入る / ← で戻る）
  ・⌘1 ⌘2 ⌘3 ⌘4            → アイコン / リスト / カラム / ギャラリー表示

動画のプレビュー中

  ・Space                   → 再生 / 一時停止（Esc で閉じる）
  ・← →                     → 1 フレームずつ移動
  ・⌥← ⌥→                   → 5 秒ずつ / ⇧⌥← ⇧⌥→ で 10 秒ずつ
  ・⌘+ ⌘-                   → 音声波形を拡大 / 縮小（⌘0 で戻す）
  ・S                       → 今のフレームを画像で書き出し
  ・⌥S                      → 色味を調整してから書き出し

書き出した画像は、動画と同じ場所に動画名のフォルダを作ってその中に入ります。


5. 対応していない形式
---------------------

MKV / WebM / MXF / R3D / BRAW などは再生できません。
一覧には表示されますが、プレビューを開くと理由が出ます。
（アプリを軽く保つため、変換ライブラリを同梱していません）
